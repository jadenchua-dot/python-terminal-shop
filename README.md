# python-terminal-shop
# 🍔 Ajumma's Fast Food Ordering System (CLI)

A command-line interactive restaurant ordering system built in Python. This project features dynamic menu navigation, real-time shopping cart management, automatic discount and tax calculations, and an integrated lucky draw mini-game.

---

## 🌟 Key Features

* **Interactive Menu Navigation:** Browse items organized by categories (Burgers, Sides, Drinks, Desserts, Combos).
* **Cart Management:** Add food items with flexible quantities, view current totals, and modify/remove items before checkout.
* **Discount & Tax Calculation:** Supports dynamic discounts (Student 10%, Staff 8%, Loyalty Member 5%) and applies 9% GST automatically.
* **Lucky Draw Mini-Game:** Winning customers get a chance to play a number-guessing game at checkout for bonus rewards.
* **Input Validation:** Clean error handling for invalid selections and non-numeric inputs.

---

## 🛠️ Built With

* **Language:** Python 3
* **Libraries:** `time`, `random` (Standard Library)
